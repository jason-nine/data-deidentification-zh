# 示例文件

这里的文件全部由 `npm run examples` 生成，人名、公司、地址、电话、证号均为程序生成的**虚构数据**，与真实个人无关。生成器会清空本目录后重建，只有本文件（README.md）会被保留。

| 目录 | 内容 | 用途 |
|------|------|------|
| `01-核心流程/` | 外包服务合同书（Word／PDF，4 页）、报价单（Word／PDF，3 页）、客户数据（Excel，60 条）、客服邮件（TXT）、项目会议记录（Markdown）、扫描文件（5 页扫描 PDF） | 演示完整的「上传 → 预览 → 复核 → 下载」流程 |
| `02-人工调整/` | 人工调整示例（TXT） | 演示取消误判、整类取消、框选新增 |
| `03-还原/` | 已去标识化的合同书与编码表、客服邮件与编码表，以及缺列、格式错误、编码重复的 CSV | 演示「还原」标签页与各种错误处理 |
| `04-检测规则/` | 自定义规则示例（TXT） | 演示停用内置规则、以正则新增员工编号／病历号／客户编号 |
| `06-格式与边界/` | 不支持的格式（JSON）、原文含标记样式（TXT）、如何生成超大文件（Markdown）、空白页无文字（PDF） | 演示格式限制与边界情况 |

## 重新生成

```bash
npm run examples
```

需要本机安装 Chrome（用于把 HTML 渲染成模拟扫描的 PDF）。生成器同时会把同一批文件以 ASCII 文件名写入 `public/samples/`，随站点部署，供网页上的「用示例体验」使用。

## 关于扫描文件

`01-核心流程/扫描文件.pdf` 是 5 页纯影像 PDF，没有文字层，需要在浏览器内以 OCR 识别。各页内容为：中文信函（含手写批注与机房照片）、蓝笔手写的会员申请表、横式名册表格、英文 Invoice、中英双语名片。生成时会一并输出「原稿」答案，`npm run eval:ocr` 用它评分识别效果。
