文件去标识化工具

纯前端、数据不出电脑的文件去标识化工具。上传 PDF、Word、Excel、TXT、Markdown 或粘贴文字，自动检测姓名、身份证号、手机、固定电话、地址、邮箱、公司名称、统一社会信用代码与自定义标识符；预览、人工复核后下载去标识化文件与 CSV 编码表，之后可完整还原。

关于文件去标识化工具

文件去标识化工具是一个免费、开源、纯前端的在线工具，用来把 PDF、Word、Excel、TXT、Markdown 文件或粘贴的文字中的个人信息（姓名、身份证号、手机、固定电话、地址、邮箱、公司名称、统一社会信用代码、自定义标识符）自动检测并以唯一编码取代，同时生成 CSV 编码表，以后可凭编码表完整还原。所有处理都在浏览器内完成，文件不会上传到任何服务器，离线也能使用。

适用情境

  • 交给 AI 之前：把合同、会议记录、客服对话交给 ChatGPT、Claude、Gemini 摘要或翻译前，先把姓名、电话、身份证换掉；AI 仍读得懂 [姓名]、[手机] 的语义。
  • 外包与跨部门：客户清单、报价单交给外包厂商或其他部门处理，回来后用编码表还原。
  • 研究与统计：部分保留身份证前 2 位、地址省市/区县、Email 域名，在 Excel 分组统计而不暴露个人。
  • 纸质与扫描件：申请表、名册、名片等扫描 PDF 先在浏览器内识别文字，再脱敏个人信息，表格框线与复选框照原样重绘。
  • 公开示例与教学：以「○」占位，像公文一样遮蔽个人信息后公开。

使用方式

  1. 在「去标识化」标签页拖入文件或粘贴文字，按「开始去标识化」。
  2. 在按原格式排版的预览中查看自动检测结果：预览就是下载后的样子，编码以类别名称表示（如 王[姓名]、11[身份证]），鼠标悬停可看原文与实际输出标记。
  3. 人工复核：点击标记取消误判、在「输出设置」的「按类别调整」整类取消、框选文字新增漏抓的项目。
  4. 用预览上方「输出设置」的「保留」决定要露出多少：部分保留（默认，例如 11[身份证]，只露出适合统计的字符）、全部隐藏，或自定义（逐类别保留前后几码、Email 域名、省市/区县等，方便统计，可设为默认）；不需要还原时，「标记」可改选类别 [姓名] 或空白占位「○○○」。
  5. 按「下载（文件＋编码表）」一次获取去标识化文件（与上传相同格式，文件名加 .deid）与 CSV 编码表；多个文件可一键打包成 ZIP，也可选择整批共用编码或导入上次的编码表沿用编码。
  6. 需要复原时，到「还原」标签页上传去标识化文件与编码表，即可下载还原文件。

常见问题

什么是文件去标识化？

文件去标识化是把文件中可以直接或间接识别特定个人的信息（例如姓名、身份证号、手机、地址、邮箱），以脱敏或编码取代，让文件在交给第三方、AI 服务或研究单位时不会泄漏个人信息。本工具会把每条敏感信息换成唯一的随机编码，并生成 CSV 编码表供以后还原。

我的文件会被上传到服务器吗？

不会。文件解析、个人信息检测、脱敏与输出全部在你的浏览器内以 JavaScript 完成，没有任何后端；加载页面后即使离线也能使用。浏览器只会保存你的检测规则设置，文件内容与编码表都不会落地。

支持哪些文件格式？

支持 PDF（含扫描件，会在浏览器内以 OCR 识别文字）、Word（.docx）、Excel（.xlsx）、TXT、Markdown，也可以直接粘贴文字。单档上限 100 MB，一次最多 10 个文件混合处理。不支持旧版 .doc、.xls。

可以检测哪些个人信息？

内置十七种类别。中国大陆格式：中文姓名、居民身份证号（校验位验证）、手机号码、固定电话、地址、单位名称、统一社会信用代码（校验位验证）、银行卡号（Luhn 校验）、车牌号、护照号与自定义标识符；国际与通用格式：邮箱、国际电话（验证号码有效性）、信用卡号（Luhn 校验）、美国社会安全码（SSN）、IBAN 国际银行账号、IPv4／IPv6 地址与出生日期（按「出生日期」「Date of Birth」等标签判断）。也可以用正则表达式新增自定义规则；英文姓名与地址目前需在预览中框选新增。

去标识化、假名化、匿名化有什么不同？

去标识化是泛称，指处理后无法直接识别特定个人。假名化（pseudonymization）是以代号取代可识别的数据、另外保存对照表，必要时可以还原，本工具默认的「编码」加上 CSV 编码表就属于这一类；匿名化（anonymization）则是处理到无法再回推个人、也无法还原。选「类别」或「空白占位」不会生成编码表，但是否达到匿名化，还要看保留的字符与文件中的其他信息，交付前请自行判断。

把文件交给 ChatGPT 等 AI 之前，要怎么移除个人信息？

把文件拖进本工具或直接粘贴文字，确认姓名、身份证、手机、地址、Email 等都已标记，再下载或复制去标识化后的内容交给 AI。AI 看到的是 [姓名]、[手机] 这类标记，仍能理解语义；整个过程在浏览器内完成，原始文件不会上传。默认的「编码」会让 AI 的回复保留 [姓名:6e679d] 这类标记，之后可以用编码表还原成真实数据；不需要还原时，把「标记方式」改为「类别」即可。

扫描的 PDF 或纸质扫描件可以去标识化吗？

可以。没有文字层的 PDF 会在浏览器内以 OCR（简体中文＋英文）识别，再自动检测与脱敏；表格框线、底色、复选框与文字颜色按原位置重绘，倾斜或放反的页面会先自动转正。以内置的 5 页扫描示例实测，字符召回率约 98.6%。识别仍可能有误，下载前请逐页核对。

可以一次处理多个文件吗？

可以。一次最多 10 个文件，PDF、Word、Excel、TXT、Markdown 可以混合，每个文件各自预览与复核，最后一键打包成 ZIP 下载；也可以让整批文件共用编码，同一个人在不同文件中是同一个编码。

去标识化后可以还原吗？

可以。每条敏感信息都换成 [类别:编码] 形式的唯一标记，对应关系存在 CSV 编码表中。在「还原」标签页上传去标识化文件与编码表，即可获取原格式的还原文件。编码表是还原的唯一凭证，请妥善保管。

不需要还原，可以只遮蔽、不要编码吗？

可以。在「输出设置」的「标记」改选「类别」，输出写成 [姓名]、[手机]；或选「空白占位」，像公文一样以「○」取代每个字（分隔符号保留，例如 138-○○○○-○○○○）。这两种方式只下载去标识化文件、不生成编码表，以后无法还原；「空白占位」会保留原本的字数，需要更高的匿名性请选「类别」。默认的「编码」仍可还原。

去标识化后的数据还能拿来统计吗？

可以。预览上方「输出设置」的「保留」默认为「部分保留」，只露出适合统计的字符，例如身份证前 2 位（省级行政区）、Email 域名、地址的省市/区县，输出如 11[身份证:a3f9c2]；改选「自定义」可以逐类别调整，在 Excel 用 LEFT／RIGHT 就能分组统计，仍可用编码表完整还原。多个文件可以选择整批共用编码，或导入上次的编码表沿用旧编码，让同一个人在不同文件中是同一个编码。保留的字符越多越容易识别出个人，请根据接收对象斟酌。

输出的文件会保留原本的格式吗？

Word 与 Excel 直接改写文字节点，样式、表格、页眉页脚与工作表结构都保留；PDF 依原始坐标重建文字版面并内嵌中文字体，但图片、图形与原字体不会保留。

PDF 为什么不是用黑框盖住敏感文字？

用色块覆盖的 PDF，底层文字仍然可以被复制或提取出来。本工具改以文字重建的方式输出 PDF，敏感文字会真正从文件中移除，不会残留在输出文件内。

自动检测会不会有误判或漏抓？

会。中文姓名与地址无法靠规则做到零误判、零漏抓，所以自动检测只是建议：预览画面可以点击标记取消误判、在「按类别调整」整类取消，或框选文字手动新增漏抓的项目，确认后再下载。

这个工具要收费吗？可以自行部署吗？

完全免费，并以 MIT 授权开源。执行 npm run build 生成的 dist/ 是纯静态网站，可以放到 GitHub Pages、内网文件服务器或任何静态空间自行部署，也可以直接以文件方式打开。

In English

Data De-identification Tool is a free, open-source, browser-only tool for redacting personal data (PII) in Simplified Chinese (Mainland China) documents. It detects names, national ID numbers, mobile and landline numbers, addresses, email addresses, company names and tax IDs in PDF (including scanned PDFs, read with in-browser OCR), Word, Excel, TXT and Markdown files, lets you review every match, and exports the redacted file in its original format. Each value becomes a reversible code with a CSV mapping table, or a plain category label or ○ placeholders when no restoring is needed. Files never leave your browser.
